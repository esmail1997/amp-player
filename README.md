# AMP Player

مشغّل فيديو لنظام Windows يسهّل متابعة المحتوى للأشخاص ذوي الإعاقة البصرية، من خلال قراءة الترجمة صوتياً باستخدام NVDA أو محرك تحويل النص إلى كلام.

## المزايا

- قراءة ملفات الترجمة الخارجية والترجمات النصية المدمجة في الفيديو.
- واجهة عربية ودعم اتجاه الكتابة من اليمين إلى اليسار.
- التحكم بلوحة المفاتيح وقوائم قياسية لتسهيل التنقل.
- تكامل مع قارئ الشاشة NVDA وإعدادات للنطق وخفض صوت الفيديو أثناء القراءة.
- توحيد مصادر الترجمة لتقليل تكرار قراءة الأسطر.
- خيارات للترجمات الصورية والمحروقة عبر OCR، وتتطلب محرك تعرف بصري منفصلاً؛ النسخة الحالية لا تتضمن هذا المحرك.

## التشغيل

يتطلب البرنامج Windows 10 أو Windows 11. عند توفر إصدار للتنزيل، حمّل المثبّت من قسم Releases وثبّته ثم افتح ملف فيديو وحدّد الترجمة المناسبة. يُوصى باستخدام NVDA للاستفادة من تكامل قارئ الشاشة.

## التشغيل من المصدر

ثبّت متطلبات requirements.txt ثم شغّل main.py. يتوفر ملف run.bat لتسهيل التشغيل على Windows. يمكن تشغيل الفحص الذاتي باستخدام python main.py --selftest.

## حالة التحقق

اجتازت النسخة المجمعة المعدلة فحصها الذاتي وفق تقرير البناء السابق. لا يعني ذلك التحقق اليدوي من نطق جميع عناصر الواجهة بواسطة NVDA. يتطلب OCR إعداداً إضافياً ولم يُختبر التعرف البصري الفعلي ضمن الإصلاح الأخير.
